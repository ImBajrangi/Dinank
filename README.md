# Dinank

A modern, high-performance Flutter mobile application for educators to track, celebrate, and send 1-tap WhatsApp birthday greetings to students and parents with 100% offline Kotlin WorkManager background alarms and real-time Google Sheets & Excel cloud sync.

## ✨ Features
- 🎂 **Daily Birthday Radar & Horizon Forecast**: Bento dashboard tracking today's celebrants, upcoming 7-day forecast, and monthly birthday breakdowns.
- 💬 **1-Tap WhatsApp Greetings**: Instant personalized message generator with dynamic tags (`{name}`, `{class}`, `{age}`, `{teacher_name}`) and bold/italic formatting for both students and parents.
- ⚡ **Google Sheets Live Sync**: Connect multiple Google Sheet roster URLs with background auto-sync, CSV offline caching, and instant upserting.
- 📊 **Excel / CSV Roster Engine**: Smart header mapping algorithm supporting standard variants (`Student Name`, `DOB`, `Batch`, `Phone`, `Parent Contact`).
- ⏰ **Native Android Kotlin WorkManager**: 100% reliable background alarm service delivering daily morning notifications without requiring the app to be open.
- 🎨 **Modern Dark & Light UI**: Responsive Netflix/Uber inspired capsule navigation bar and Bento design system.
